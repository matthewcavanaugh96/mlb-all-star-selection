# mlb-all-star-selection
Using batting statistics on every MLB player with a plate appearance before the All-Star break in the 2023 season, we will train a model on predicting whether each one was named to the All-Star Game.

Once we have validated our model, we will test it on data from the 2024 season.
With the Logistic Regression, we will print each prediction's confidence and "grade" it in comparison to its accuracy.

In the future, the training dataset could be expanded with more seasons.
